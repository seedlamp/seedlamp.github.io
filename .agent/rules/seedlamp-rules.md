# Rules for AI helpers - Seedlamp Studio website (seedlamp.com)

Read these before every task. If a task breaks a rule, stop and ask.

## What this is
- Static Jekyll site for Seedlamp Studio (published from this repo, CNAME = seedlamp.com).
- English pages in the root, Czech pages in /cs. Game pages in /orbjar.
- Shared parts: _includes (header/footer), _data.

## Never
- Never read, open, copy or write anything in E:\ClaudeAI\keys (secrets).
- Never commit, push or deploy. Change files only, then show the diff and wait.
- Never touch folders outside this repo (especially G:\STUDIO - Development\=My Projects=\OrbJar).
- Never add tracking, cookies, ads code or new third-party scripts without asking.
- Never change privacy.html or app-ads.txt without asking (they are linked from Google Play).

## Text
- Plain "-" only. Never long dashes (em/en dash).
- Keep texts short and general; players discover the game themselves.
- Every English change also goes to the Czech page in /cs. The Czech text must fit the same space as English (shorten it if needed).
- Do not invent facts (dates, prices, numbers). Ask if unsure.

## Work style
- Smallest change that does the task. Do not redesign or reformat files you were not asked to change.
- One task at a time. When done: list the changed files + a short summary + anything you were unsure about.
- Research answers: list only the sources you actually used, with their dates; mark anything unverified.
