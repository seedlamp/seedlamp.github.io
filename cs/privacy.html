Tento web

Tento web nepoužívá žádné cookies, žádnou reklamu ani obsah z jiných webů (kromě počítadla návštěv níže a traileru, pokud ho spustíš); i písma se načítají odsud. Web běží na službě GitHub Pages společnosti GitHub, Inc. Když otevřeš stránku, GitHub zpracovává technické údaje, jako je tvoje IP adresa, aby ti stránku doručil a udržel službu bezpečnou, jak popisuje GitHub General Privacy Statement. Tyto záznamy nedostáváme. Abychom věděli, kolik lidí web navštíví a které stránky čtou, počítáme návštěvy službou GoatCounter, šetrným počítadlem bez cookies: zaznamená stránku, odkud návštěva přišla (například z naší hry nebo z Google Play), prohlížeč a jeho jazyk, velikost obrazovky a zemi odvozenou z IP adresy a uchovává jen denní součty - žádnou IP adresu ani tvůj profil. Vidíme jen tyto součty; důvodem je náš oprávněný zájem vědět, že web funguje a je užitečný. Stránka Orbjar ukazuje náš trailer nejdřív jen jako obrázek; teprve když ho spustíš, video se načte z YouTube (v režimu rozšířené ochrany soukromí) a od té chvíle zpracovává údaje Google podle svých Zásad ochrany soukromí. Když přepneš jazyk webu nebo když web otevře hra ve svém jazyce, tahle volba se zapamatuje v prohlížeči (local storage), aby se další stránka otevřela ve stejném jazyce; z tvého zařízení nikam neodchází.
